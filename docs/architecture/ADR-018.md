# ADR-018: Documentation language is Simplified Technical English

Status: Accepted

Date: 2026-10-29

## Context

Readers of the documentation include humans with different native languages and AI agents.
Ambiguous text causes wrong implementations and wrong use.
ASD-STE100 Simplified Technical English (STE) is a controlled language for technical documents.

## Decision

Write all text in ASD-STE100 Simplified Technical English. This includes ADRs, PRDs, README files, the agent skill, CLI help, and error messages.

Apply these rules:

- Use short sentences. Procedures have a maximum of 20 words for each sentence. Descriptions have a maximum of 25 words.
- Use the active voice.
- Use the imperative for instructions.
- Write one instruction in each sentence.
- Give each word one meaning only.
- Do not use idioms.
- Do not use marketing words.
- Use Markdown.

## Consequences

Positive:

- Non-native readers understand the text more easily.
- AI agents follow instructions more reliably.
- Translation is easier.

Negative:

- Writing takes more time.
- Some text is longer because each sentence has one idea only.
- Reviews must also check the language rules.
